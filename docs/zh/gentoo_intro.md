# Gentoo Linux: 简介与哲学

Gentoo Linux 是一个独特的、基于源码构建的 Linux 发行版，其核心哲学是完全自定义、极致性能和用户自主选择。与主流的预编译发行版（如 Ubuntu、Fedora 或 Debian）不同，Gentoo 提供了从零开始构建操作系统的工具，所有软件包都直接在您的机器上进行编译。

---

## 1. 核心哲学

Gentoo 的首要哲学是**选择**。操作系统的每一个方面都可以自定义：
*   **编译时选项：** 精确选择您的应用程序中包含哪些功能。
*   **初始化系统（Init System）：** 在 OpenRC（默认，轻量级）或 systemd 之间进行选择。
*   **系统配置文件（Profiles）：** 在桌面（desktop）、服务器（server）、加固（hardened）或开发者（developer）配置文件之间进行选择。
*   **C 标准库（Libc）实现：** 使用标准的 glibc 或轻量级的 musl。

---

## 2. 为什么使用基于源码的操作系统？

1.  **量身定制的性能：** 软件包在编译时使用专门针对您的 CPU 架构的优化标志（例如 `-march=native`），从而释放最佳的指令流水线利用率。
2.  **没有无用冗余：** 通过禁用您不需要的编译功能，可以减小二进制文件体积、降低内存占用并减少安全攻击面。
3.  **教育价值：** 构建 Gentoo 的过程将教会您操作系统、工具链、库和内核是如何整合在一起工作的。
