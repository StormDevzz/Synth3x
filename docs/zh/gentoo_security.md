# Gentoo Hardened 安全与隔离

Gentoo Hardened 是一个旨在为 Gentoo Linux 带来高级安全功能的项目。Synth3x 运行在 Hardened 系统配置文件上，以确保系统完整性、进程隔离和网络隐私。

---

## 1. 工具链加固

加固的编译器配置文件在构建和编译期间强制执行安全标志：
*   **地址无关可执行文件（PIE）：** 强制二进制文件加载在随机内存地址，防止缓冲区溢出重定向攻击。
*   **堆栈破坏保护器（SSP）：** 在堆栈上插入保护变量（金丝雀），以便在发生堆栈溢出时检测并中止执行。
*   **Fortify Source：** 在编译时将不安全的字符串和内存函数替换为具有边界检查的替代函数。

---

## 2. 地址空间保护

Gentoo Hardened 利用内核级保护来防止内存执行漏洞利用：
*   **地址空间布局随机化（ASLR）：** 随机化活动进程地址空间（堆栈、堆、库）的布局。
*   **非可执行内存（NX/W^X）：** 确保内存页要么是可写的，要么是可执行的，但绝不能两者兼有，以此来防止注入的 Shellcode 执行。

---

## 3. 网络隐私与防火墙

Synth3x 将系统范围的网络流量通过 Tor 洋葱网络路由。
*   **透明代理：** 自定义防火墙规则（`/etc/nftables.rules`）将所有传出 TCP 流量重定向到本地 Tor 透明代理端口（9040）。
*   **防止 DNS 泄漏：** 所有 DNS 查询都被拦截并转发到 Tor 的安全解析器，防止被 ISP（互联网服务提供商）追踪。
