# Linux From Scratch: Introduction & Prerequisites

Linux From Scratch (LFS) is a project that provides you with step-by-step instructions to build your own custom Linux system from source code. Doing so offers deep insights into how a Linux operating system is constructed, how components depend on each other, and how the boot process is initialized.

---

## Detailed Explanation

To begin building an LFS system, you need a host operating system with a compatible development toolchain. Requirements include:
- GCC 8.0 or later
- Binutils 2.30 or later
- Glibc 2.28 or later
- Linux Kernel API Headers
- Gawk, Make, Tar, and Bash configured as default shell.

---

## Best Practices & Tips

> [!TIP]
> Ensure your host system meets all requirements before starting. You can verify using a standard host validation script.
