# Selecting Global Gentoo Mirrors

Using fast, close regional mirrors is essential to speed up package and stage archive downloads.

---

## 1. Official Mirror Redirector (Bouncer)

The Gentoo Bouncer service automatically evaluates your IP address and redirects you to the closest mirror.
*   **Redirector URL:** `https://bouncer.gentoo.org/`

---

## 2. Fast Global Mirrors

### North America:
*   `https://gentoo.osuosl.org/` (Oregon State University)
*   `http://mirrors.rit.edu/gentoo/` (Rochester Institute of Technology)

### Europe:
*   `https://mirror.bytemark.co.uk/gentoo/` (United Kingdom)
*   `https://ftp.halifax.rwth-aachen.de/gentoo/` (Germany)
*   `https://mirrors.netix.net/gentoo/` (Bulgaria)

### Asia / Oceania:
*   `https://mirrors.ustc.edu.cn/gentoo/` (China)
*   `https://ftp.jaist.ac.jp/pub/Linux/Gentoo/` (Japan)
*   `https://mirror.aarnet.edu.au/pub/gentoo/` (Australia)
