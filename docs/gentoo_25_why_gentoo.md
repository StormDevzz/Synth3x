# Why Gentoo? — The Reason for Existence

Gentoo exists because not every user wants to be told what their operating system should be.

Most Linux distributions ship pre-compiled binaries with fixed feature sets. They decide for you which init system, which libc, which compiler flags, and which components are included. Gentoo takes the opposite approach: it gives you the raw ingredients and trusts you to build what you need.

## The Core Idea

Gentoo exists to preserve **user sovereignty** over software. In an era where operating systems increasingly lock down choices, restrict modifications, and push automatic updates, Gentoo remains a distribution that:

- Compiles everything from source, optimized for your exact hardware
- Lets you choose every feature via USE flags
- Never forces a desktop environment, init system, or kernel configuration
- Educates users about how their system actually works

## Who Gentoo Is For

Gentoo is for those who want to understand, not just use. It is a distribution for developers, system administrators, security researchers, and anyone who believes that controlling your computing environment is a fundamental right — not a privilege.

## Why Synth3x Uses Gentoo

Synth3x builds on Gentoo because Gentoo's philosophy aligns with our own: amnesic, hardened, source-based, and fully auditable. Gentoo provides the foundation; Synth3x provides the amnesic live environment, the Wayland compositor, and the security-hardened defaults — all without compromising the user's freedom to go deeper.
