AmnesiaIDE is a lightweight GUI IDE for Synth3x-Anon OS.
It is written in pure Rust (eframe/egui), runs as its own
native window, and supports syntax highlighting for five
languages plus a built-in compile & run panel.

──────────────────────────────────────────────────────
KEYS
──────────────────────────────────────────────────────
  Ctrl+O     Open file
  Ctrl+S     Save file
  F5         Compile & Run
  Quit via File > Quit or window close

──────────────────────────────────────────────────────
LANGUAGES
──────────────────────────────────────────────────────
  .c, .h         → C   (gcc)
  .cpp/.cc/.cxx  → C++ (g++)
  .cs            → C#  (mcs)
  .rs            → Rust (rustc)
  .asm/.s/.S     → ASM (nasm + ld)

Syntax highlighting with keywords, numbers, strings,
comments, and type highlighting for all five languages.

──────────────────────────────────────────────────────
OUTPUT PANEL
──────────────────────────────────────────────────────
Click "Terminal" in the menu bar or press F5 to show
the build output panel. Compilation results, errors,
and warnings appear here.

──────────────────────────────────────────────────────
BUILD & RUN
──────────────────────────────────────────────────────
File > Compile & Run or press F5 to compile.
On success, run with: /tmp/amnesia_out
