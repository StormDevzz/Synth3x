AmnesiaIDE is a lightweight terminal IDE for Synth3x-Anon OS.
It is written in Rust with a C core, uses minimal resources,
and stays running entirely inside your terminal.

──────────────────────────────────────────────────────
KEYS
──────────────────────────────────────────────────────
  ^O       Open file
  ^S       Save file
  ^R       Build & run (compiles via system toolchain)
  ^Q       Quit
  ^G       Go to line
  ^K       Kill (delete) current line
  ^U       Clear current line
  F1-F3    Terminal panel (open)
  F4       Toggle terminal panel
  Arrows   Move cursor
  Home     Line start
  End      Line end
  Tab      4-space indent

──────────────────────────────────────────────────────
LANGUAGES
──────────────────────────────────────────────────────
  .c, .h        → C   (gcc)
  .cpp/.cc/.cxx  → C++ (g++)
  .cs            → C#  (mcs)
  .rs            → Rust (rustc)
  .asm/.s/.S     → ASM (nasm + ld)

Syntax highlighting with keywords, numbers, strings,
comments, and bracket matching for all five languages.

──────────────────────────────────────────────────────
TERMINAL PANEL
──────────────────────────────────────────────────────
Press F4 to open a built-in terminal below the editor.
Type commands directly — no need to switch windows.
Use F4 again to close it.

──────────────────────────────────────────────────────
BUILD & RUN
──────────────────────────────────────────────────────
Press ^R to compile the current file.
Output appears in the terminal panel.
On success, run the binary with: /tmp/amnesia_out

──────────────────────────────────────────────────────
PERSISTENCE (Synth3x-Anon)
──────────────────────────────────────────────────────
In Amnesic mode, save your files to /persist/AmnesiaIDE/
to keep them across reboots:
  mkdir -p /persist/AmnesiaIDE
  cd /persist/AmnesiaIDE
  amnesia-ide myproject.rs
